# 🌿 Photosynthesis Explorer: Quantum Biophysics Interactive Simulator

A cutting-edge, browser-based interactive learning tool that brings photosynthesis to life through molecular simulations, quantum visualizations, and hands-on experimentation. Experience the elegant quantum mechanics and biophysical principles that power Earth's most efficient energy system.

## 🧪 What It Does

Interactive web application that lets you:

- **Visualize molecular machines** in real-time (CF₀CF₁ ATP synthase, Kok S-state cycle, Z-scheme electron transport)
- **Experiment with biophysical parameters** (photon flux, pH gradients, inhibitors, temperatures)
- **Explore evolutionary adaptations** (C3 vs C4 vs CAM plant strategies)
- **Master photochemistry through challenges** (8 quiz questions covering quantum yields, enzyme kinetics, and thermodynamic limits)
- **Listen to quantum events** (Web Audio API synthesizes photon absorption, electron transfers, and proton pumping)

## 🔬 Key Features

### Molecular Scale Simulations
- **ETC Simulator**: Watch photons drive water splitting, Q-cycle proton pumping, and rotary ATP synthesis
- **Kok S-State Clock**: Visualize the period-4 oxygen evolution mechanism with single-photon precision  
- **Z-Scheme Ladder**: Thermodynamic electron waterfall from water oxidation to NADPH reduction
- **Calvin Vortex**: Complete carbon fixation cycle with RuBisCO oxygenation vs carboxylation

### Advanced Biophysics
- **Quantum Coherence**: Real-time exciton wavepacket superposition in LHCII/FMO complexes
- **Photosynthetic Efficiency Metrics**: Real-time calculation of quantum yields and thermodynamic efficiencies
- **Pharmacological Inhibition**: DCMU, DBMIB, FCCP effects on electron flow and ATP synthesis
- **Climate Integration**: Temperature, CO₂, and drought effects on photosynthetic pathways

### Interactive Learning
- **8-Tab Navigation**: Comprehensive coverage from light reactions to synthetic biology frontiers
- **Quiz System**: 8 questions on molecular mechanisms, stoichiometry, and evolutionary trade-offs
- **Modal Inspectors**: Deep dives into protein structures and mechanisms
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices

## 📊 Technical Stack

- **Core Engine**: Vanilla JavaScript with Web Audio API
- **Visualization**: 6 HTML Canvas elements for real-time molecular dynamics
- **Physics Models**:
  - Kok S-state water oxidation (Joliot-Joliot mechanism)
  - Mitchellian Q-cycle proton translocation
  - CF₀CF₁ rotary motor mechanics (14 H⁺/3 ATP stoichiometry)
  - Calvin-Benson-Bassham cycle stoichiometry (6 CO₂ + 18 ATP + 12 NADPH)
- **UI Framework**: Modern CSS with glassmorphism, CSS Grid, Flexbox
- **Design**: Custom color palette representing photosynthesis (emerald, cyan, gold, magenta)
